# user-service — сервис профилей пользователей

`user-service` хранит и предоставляет профильные данные пользователей Training Center Platform.

Сервис не отвечает за регистрацию, вход в систему, пароли, роли или блокировку учётной записи. Эти функции находятся в `auth-service`.

## Ответственность сервиса

- получение профиля пользователя по идентификатору;
- получение списка профилей пользователей;
- хранение профильных данных пользователя;
- предоставление профильных данных другим микросервисам.

Создание и синхронизация профилей будут реализованы отдельными задачами через события Kafka.

## Технологии

- Java 21;
- Spring Boot 3;
- Spring Web;
- Spring Data JPA;
- PostgreSQL;
- Liquibase;
- Spring Cloud Netflix Eureka Client;
- Swagger / OpenAPI;
- Lombok;
- SLF4J + Logback.

## Порт

Сервис запускается на порту:

```text
8081
```

## База данных

Используется отдельная база данных:

```text
user_db
```

Локальное подключение:

```text
jdbc:postgresql://localhost:5433/user_db
```

Структура базы данных управляется через Liquibase.

## Service Discovery

`user-service` регистрируется в `discovery-service` под именем:

```text
user-service
```

Eureka Server:

```text
http://localhost:8761/eureka/
```

После запуска сервис должен отображаться в Eureka Dashboard со статусом `UP`.

## API

### Получить профиль пользователя

```http
GET /api/v1/users/{id}
```

Пример ответа:

```json
{
  "id": "11111111-1111-1111-1111-111111111111",
  "firstName": "Иван",
  "lastName": "Иванов",
  "email": "ivan@example.com",
  "createdAt": "2026-09-11T10:00:00",
  "updatedAt": "2026-09-11T10:00:00"
}
```

### Получить список профилей пользователей

```http
GET /api/v1/users
```

Сервис возвращает список `UserResponse`.

## Логирование

Для логирования используется стандартный стек Spring Boot:

```text
SLF4J + Logback
```

Основные операции получения пользователей логируются на уровне `INFO`, отсутствие пользователя — на уровне `WARN`.

Пароли, токены и другие чувствительные данные в логах отсутствуют.

## Разделение ответственности с auth-service

`auth-service` отвечает за:

- регистрацию;
- аутентификацию;
- JWT;
- пароль;
- роли;
- блокировку и разблокировку учётной записи;
- изменение и удаление учётной записи.

`user-service` отвечает только за профильные данные и их предоставление другим сервисам.

В публичном API `user-service` отсутствуют `POST`, `PUT`, `PATCH` и `DELETE` для управления профилями.

## Запуск

Перед запуском необходимо:

1. запустить PostgreSQL для `user-service`;
2. запустить `discovery-service`;
3. запустить `user-service`.

После запуска проверить:

- сервис успешно подключился к `user_db`;
- Liquibase выполнил миграции;
- сервис зарегистрировался в Eureka;
- Swagger UI открывается;
- GET-endpoint'ы работают корректно.
